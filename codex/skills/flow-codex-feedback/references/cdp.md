# Feedback 浏览器兼容入口

浏览器规则统一读取 `../../flow-codex-sites/SKILL.md`，个人手册维护读取其 `references/maintenance.md`。本文件只保留 feedback 的衔接，不重复定义工具选择或维护许可。

Discover 先读个人 `.flow/worksites/README.md`，选平台和具体操作；未命中时读项目 `.flow/cdp/README.md`。历史 CDP 文档中的业务参数可参考，CDP 步骤不覆盖 Edge 优先规则。缺手册只记缺口，不停止调查。

Trace/Verify 使用站点技能完成当前授权操作，再把结果与证据追加到原 feedback 报告。新操作成功后自动沉淀到个人手册，不因维护文档再次询问；站点技能独立调用时不创建 feedback。

feedback 的只读查库及数据修复工单边界不变；平台手册不能授权写库。账号凭据、Cookie、Token 不写入手册或调查正文。
