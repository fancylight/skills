# 工作站点操作

本技能只负责当前任务需要的站点操作和可复用知识，不启动 feedback、设计、派发或测试状态机。调用方继续负责原任务。

## 资料与工具

- 个人资料根目录为用户主目录下 `.flow/worksites/`。先读 `README.md` 索引，再读命中的平台 `README.md` 和具体操作；不要遍历全部手册。
- 若当前项目仍有 `.flow/cdp/README.md`，可用作旧知识索引。旧 CDP 步骤不能覆盖本技能的工具优先级；记录来源及实际验证范围。
- 默认使用当前可用的 Edge 扩展控制工具，先读工具文档。用户明确指定 CDP，或 Edge 无法完成具体操作时才使用备用，记录具体缺口。不要默认启动调试端口，不假定工具支持任意 fetch、页面内部变量或网络抓取。
- 复用适用的已登录页面；若标签页被其他任务使用，开同站点独立标签页，不抢占、重置或关闭他人页面。只维护当前任务创建的页面。

## 操作

1. 明确平台、环境和当前目标；沿用任务已有租户、项目、服务、时间范围、时区、业务 ID 和 traceId，不跨站重新猜测。
2. 从索引选择具体操作。匹配时核对当前账号角色、环境及关键控件，直接按手册执行；不因进入平台就完整分析所有页面。新操作或失效步骤才局部探索。
3. 劳务等动态菜单按当前租户／项目定位功能；旧菜单路径只是该上下文的线索。GBP 等复杂平台按模块加载，数据库运维只是其能力之一，不能套用于构建发布。
4. 执行当前授权动作。查状态／日志与触发构建、发布、写库、Pod 命令、Arthas 诊断分开；手册不能授权。首次验证优先最小只读输入，不为了补齐手册制造业务写入。
5. 用实际结果确认完成，区分空结果、登录失效、权限不足、导航变化、工具不支持。只看到入口不算查询通过；某环境成功不代表其他租户或平台全部操作通过。失败只影响对应操作，独立工作继续。
6. 将结果交回当前任务，不创建 feedback 目录、不写 task 状态。已有 feedback 调查只在原报告追加对应证据。

## 沉淀与计时

成功发现可复用的新操作后自动更新个人手册与索引，不额外请求维护许可。新增平台用 [平台模板](assets/platform.md.tmpl)，新增操作用 [操作模板](assets/operation.md.tmpl)。详细规则见 [维护说明](references/maintenance.md)。

在当前任务记录操作开始与结束时间、平台／操作、环境范围、结果、重复探索次数及用户介入原因；用工具取得时间，不估造活跃耗时。没有准确起点时标未知。集成测试内复用既有 timeline 阶段记录，并将站点操作明细写入对应证据；不另起预算、不重复累计、不成为 PASS 门禁。普通操作不要求建立独立报告目录。

账号只记录标识、角色、登录方式；不保存密码、Cookie、Token 或完整认证请求。手册中的业务 ID 用参数表示，当前具体输入和查询结果留在原任务，必要时脱敏。
